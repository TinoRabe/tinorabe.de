What changed in 2026

Dynamics 365 no longer means standard data model

Since May 2026, the Customer self-service, Employee self-service, Partner and Community templates create enhanced data model sites with Bootstrap 5. They need Power Pages Core Package v1.1.2602.230 or later. Four Dynamics 365 templates still create standard data model sites, even when the enhanced data model is switched on.

Enhanced data model

10 templates

Starter layouts 1 to 5, Blank page, Application processing, Program registration, Schedule and manage meetings, FAQ, plus four Dynamics 365 templates.

Standard data model only

4 templates

Customer Portal, Field Service, Modern Community and Order Returns, all Dynamics 365.

Not documented

2 templates

Event portal and the Supply Chain Management customer site. Learn doesn't list them for either data model.

Migration: the migration utility only supports sites whose original template is listed as supported. Microsoft's guidance: if your template isn't listed, don't run the utility on that site. For the four Dynamics 365 templates, the enhanced data model page still says existing sites can't be migrated yet, while the migration overview lists them as supported.

Method

How this was checked

  • Every fact comes from a Microsoft Learn page, linked on the template: the template pages, Enhanced data model, Migration overview and Create additional sites.
  • Tables and pages are listed only where Microsoft documents them. For Dynamics 365 templates, Learn describes the purpose, not the inventory.
  • "Not documented" means Learn says neither yes nor no. Check it in your environment before you rely on it.
