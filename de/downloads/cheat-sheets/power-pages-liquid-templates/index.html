Power Pages Liquid Templates

Kurzreferenz im Terminal-Stil • Beispiele mit Ein- und Ausgabe • mit Praxistipps

if / elsif / else
Grundlagen
Bedingte Logik: Code abhängig von Bedingungen ausführen
Syntax
{% if user %}
  Welcome, {{ user.fullname | escape }}
{% elsif request.params.ref == 'newsletter' %}
  Welcome, newsletter reader
{% else %}
  Welcome, Guest
{% endif %}
Ausgabe (angemeldeter Benutzer)
Welcome, Dave Bowman
Tipp: Für mehrere Bedingungen elsif statt verschachtelter if-Anweisungen nutzen, das liest sich besser
for loop
Grundlagen
Über Arrays oder Bereiche iterieren
Syntax (Array)
{% for item in entityview.records %}
  {{ item.fullname }}
{% endfor %}
Syntax (Bereich mit limit)
{% for i in (1..5) limit:3 %}
  Item {{ i }}
{% endfor %}
Tipp: Mit forloop.first, forloop.last und forloop.index lassen sich Sonderfälle in Schleifen behandeln
Performance: Verschachtelte Schleifen über große Datenmengen vermeiden, besser Filter wie batch oder group_by nutzen
assign
Grundlagen
Variablen anlegen und zuweisen
Syntax
{% assign my_variable = "Hello World" %}
{% assign total = price | times: 2 %}
{{ my_variable }} - Total: {{ total }}
Tipp: Für mehrzeilige Inhalte oder mit Liquid-Logik gebaute Zeichenketten capture nutzen
date
Filter
Datum und Uhrzeit formatieren
Syntax
{{ entity.createdon | date: "dd MMM yyyy" }}
{{ now | date: "yyyy-MM-dd HH:mm:ss" }}
Ausgabe
15 Jan 2025 2025-01-15 14:30:45
Tipp: Für das aktuelle UTC-Datum das Objekt now verwenden. Die Website speichert den Wert zwischen, er wird nicht bei jeder Anfrage neu ermittelt
upcase / downcase
Filter
Zeichenketten in Groß- oder Kleinbuchstaben umwandeln
Syntax
{{ "power pages" | upcase }}
{{ "HELLO" | downcase }}
Ausgabe
POWER PAGES hello
join
Filter
Array-Elemente mit Trennzeichen verbinden
Syntax
{% assign names = "John,Mary,Tom" | split: "," %}
{{ names | join: " | " }}
Ausgabe
John | Mary | Tom
where
Filter
Array nach Attributwert filtern
Syntax
{% assign active_users = entityview.records | where: 'statecode', 0 %}
{% for user in active_users %}
  {{ user.fullname }}
{% endfor %}
Tipp: Mit dem Filter except umgekehrt filtern (alle Elemente, die NICHT dem Wert entsprechen)
order_by
Filter
Array nach Attribut sortieren (auf- oder absteigend)
Syntax

{{ entityview.records | order_by: 'fullname' | join: ', ' }}


{{ entityview.records | order_by: 'fullname', 'desc' | join: ', ' }}
Ausgabe
Alice, Bob, Charlie Charlie, Bob, Alice
page
Objekt
Eigenschaften der aktuellen Seite abrufen
Syntax
{{ page.title }}
{{ page.url }}
{{ page.description }}
{{ page.id }}
Tipp: page.url für Canonical-Links und Breadcrumbs nutzen
user
Objekt
Eigenschaften des aktuellen Benutzers (Kontakt) abrufen
Syntax
{% if user %}
  {{ user.fullname | escape }}
  {{ user.emailaddress1 | escape }}
  {{ user.id }}
{% endif %}
Sicherheit: user ist bei anonymen Besuchern null, persönliche Ausgaben deshalb in {% if user %} einschließen
request
Objekt
Daten der HTTP-Anfrage abrufen (URL, Query-Parameter usw.)
Syntax
{{ request.url }}
{{ request.path }}
{{ request.params.id }}
{{ request.query }}
Beispiel (URL: /page?id=123&name=test)
request.params.id → 123 request.params.name → test
Tipp: Mit request.params dynamische Seiten auf Basis von URL-Parametern bauen
entitylist
Dataverse
Dataverse-Datensätze über eine Listenkonfiguration laden
Syntax
{% entitylist name: "Active Contacts" %}
  {% entityview %}
    {% for item in entityview.records %}
      {{ item.fullname }}: {{ item.emailaddress1 }}
    {% endfor %}
  {% endentityview %}
{% endentitylist %}
Tipp: Die Liste liefert nur die Konfiguration. Die Datensätze gibt das Tag entityview innerhalb des Blocks aus
Hinweis: Alle Dataverse-Daten, die die Website abfragt, werden serverseitig zwischengespeichert, nicht nur Listen
entityview
Dataverse
Dataverse-Datensätze über eine gespeicherte Ansicht laden
Syntax
{% entityview logical_name:'contact', name:'Active Contacts' %}
  Total: {{ entityview.total_records }}
  {% for contact in entityview.records %}
    {{ contact.fullname }}
  {% endfor %}
{% endentityview %}
Tipp: Mit Filtern wie where und order_by kombinieren, um die Ergebnisse weiterzuverarbeiten
fetchxml
Dataverse
FetchXML-Abfrage für komplexere Dataverse-Abfragen ausführen
Syntax
{% fetchxml query %}
<fetch>
  <entity name="contact">
    <attribute name="fullname"></attribute>
    <filter>
      <condition attribute="statecode" operator="eq" value="0"></condition>
    </filter>
  </entity>
</fetch>
{% endfetchxml %}
{% for contact in query.results.entities %}
  {{ contact.fullname }}
{% endfor %}
Tipp: Jedes Element mit eigenem schließenden Tag schreiben. Selbstschließende Tags wie <attribute name="fullname"/> werden hier nicht unterstützt
chart
Dataverse
Diagramm einer modellgesteuerten Power App einbetten
Syntax
{% chart id:"EE3C733D-5693-DE11-97D4-00155DA3B01E" viewid:"00000000-0000-0000-00AA-000010001006" %}
powerbi
Dataverse
Power-BI-Berichte oder -Dashboards einbetten
Syntax
{% powerbi authentication_type:"powerbiembedded" path:"https://app.powerbi.com/groups/.../reports/..." %}
Hinweis: Setzt die im Admin Center aktivierte Power-BI-Integration voraus
editable
Dataverse
CMS-Objekt für Redakteure bearbeitbar ausgeben
Syntax
{% editable page 'adx_copy' type: 'html', title: 'Page Copy' %}
{% editable snippets 'Header' type: 'html' %}
entityform
Dataverse
Basisformular (Entity Form) über Name oder ID ausgeben
Syntax
{% entityform name: 'Contact Form' %}
searchindex
Dataverse
Den Power-Pages-Suchindex abfragen
Syntax
{% searchindex query: request.params.q, page: request.params.page %}
  {% if searchindex.results.size > 0 %}
    {% for result in searchindex.results %}
      {{ result.title }}
    {% endfor %}
  {% endif %}
{% endsearchindex %}
case / when
Grundlagen
Switch-Anweisung: gegen mehrere Werte prüfen
Syntax
{% case page.title %}
  {% when 'Home' %}
    Welcome home!
  {% when 'About', 'Contact' %}
    Info page
  {% else %}
    Other page
{% endcase %}
Tipp: Ab drei Bedingungen ist case/when übersichtlicher
unless
Grundlagen
Negierte Bedingung: ausführen, wenn falsch
Syntax
{% unless user %}
  Please sign in to continue
{% endunless %}
Ausgabe (nicht angemeldet)
Please sign in to continue
Tipp: unless entspricht if not, nehmen Sie, was sich besser liest
capture
Grundlagen
Ausgabe eines Template-Abschnitts in einer Variable speichern
Syntax
{% capture greeting %}
  Hello {{ user.firstname }}, welcome!
{% endcapture %}

{{ greeting }}
Tipp: Mit capture komplexe Zeichenketten samt Liquid-Logik aufbauen
cycle
Grundlagen
Eine Gruppe von Zeichenketten reihum ausgeben, bei jedem Aufruf die nächste
Syntax
{% for item in items %}
  <div class="{% cycle 'red', 'green', 'blue' %}">
    {{ item }}
  </div>
{% endfor %}
Tipp: Ideal für Zebrastreifen in Tabellen oder wechselnde Farben
tablerow
Grundlagen
HTML-Tabellenzeilen erzeugen (muss in <table>-Tags stehen)
Syntax
<table>
{% tablerow child in page.children cols:2 %}
  {{ child.title }}
{% endtablerow %}
</table>
Tipp: Mit dem Parameter cols: die Spalten pro Zeile steuern
comment
Grundlagen
Kommentare einfügen, die nicht ausgegeben werden
Syntax
{% comment %}
  This text will not appear in the output.
  Use for documentation and notes.
{% endcomment %}
raw
Grundlagen
Liquid-Code unverarbeitet ausgeben
Syntax
{% raw %}
  {{ user.fullname }} will be displayed literally
{% endraw %}
Tipp: Ideal, um Liquid-Beispiele in Dokumentation zu zeigen
== (equals)
Operator
Prüfen, ob zwei Werte gleich sind
Syntax
{% if user.fullname == 'Dave Bowman' %}
  Hello, Dave
{% endif %}
!= (not equals)
Operator
Prüfen, ob zwei Werte ungleich sind
Syntax
{% if page.title != 'Home' %}
  Not the home page
{% endif %}
> (greater than)
Operator
Prüfen, ob der linke Wert größer als der rechte ist
Syntax
{% if entityview.records.size > 10 %}
  More than 10 records
{% endif %}
< (less than)
Operator
Prüfen, ob der linke Wert kleiner als der rechte ist
Syntax
{% if page.children.size < 5 %}
  Less than 5 children
{% endif %}
>= (greater or equal)
Operator
Prüfen, ob der linke Wert größer oder gleich dem rechten ist
Syntax
{% if entityview.page >= 1 %}
  Valid page number
{% endif %}
<= (less or equal)
Operator
Prüfen, ob der linke Wert kleiner oder gleich dem rechten ist
Syntax
{% if entityview.page <= entityview.total_pages %}
  Valid page
{% endif %}
and
Operator
Beide Bedingungen müssen wahr sein
Syntax
{% assign is_admin = user | has_role: 'Administrators' %}
{% if user and is_admin %}
  Admin user
{% endif %}
or
Operator
Mindestens eine Bedingung muss wahr sein
Syntax
{% if page.title == 'Home' or page.title == 'Index' %}
  Home page
{% endif %}
contains
Operator
Auf Teilzeichenkette oder Array-Element prüfen
Syntax
{% if page.title contains 'Product' %}
  This is a product page
{% endif %}
startswith
Operator
Prüfen, ob eine Zeichenkette mit einer Teilzeichenkette beginnt
Syntax
{% if page.title startswith 'Profile' %}
  Profile page
{% endif %}
endswith
Operator
Prüfen, ob eine Zeichenkette mit einer Teilzeichenkette endet
Syntax
{% if page.title endswith 'Forum' %}
  Forum page
{% endif %}
append
Filter
Zeichenkette an eine andere anhängen
Syntax
{{ 'filename' | append: '.pdf' }}
Ausgabe
filename.pdf
prepend
Filter
Zeichenkette einer anderen voranstellen
Syntax
{{ 'Jane Johnson' | prepend: 'Dr. ' }}
Ausgabe
Dr. Jane Johnson
capitalize
Filter
Jedes Wort mit Großbuchstaben beginnen
Syntax
{{ 'power pages rocks' | capitalize }}
Ausgabe
Power Pages Rocks
replace
Filter
Alle Vorkommen einer Teilzeichenkette ersetzen
Syntax
{{ 'Hello Dave, how are you Dave?' | replace: 'Dave', 'John' }}
Ausgabe
Hello John, how are you John?
remove
Filter
Alle Vorkommen einer Teilzeichenkette entfernen
Syntax
{{ 'Hello, Dave!' | remove: 'Dave' }}
Ausgabe
Hello, !
split
Filter
Zeichenkette an einem Trennzeichen in ein Array aufteilen
Syntax
{% assign words = 'This is a test' | split: ' ' %}
{{ words[0] }} 
{{ words.size }}
Ausgabe
This 4
Tipp: Mit einer for-Schleife kombinieren, um über die Teile zu iterieren
truncate
Filter
Zeichenkette auf eine Länge kürzen, mit Auslassungspunkten
Syntax
{{ 'This is a long run of text' | truncate: 10 }}
Ausgabe
This is...
Tipp: Die Auslassungspunkte (...) zählen zur Zeichenanzahl
strip_html
Filter
Alle HTML-Tags aus einer Zeichenkette entfernen
Syntax
{{ '<p>Hello <strong>World</strong></p>' | strip_html }}
Ausgabe
Hello World
newline_to_br
Filter
Zeilenumbrüche in <br />-Tags umwandeln
Syntax
{{ note.notetext | newline_to_br }}
Tipp: Nützlich, um mehrzeilige Benutzereingaben als HTML anzuzeigen
remove_first
Filter
Erstes Vorkommen einer Teilzeichenkette entfernen
Syntax
{{ 'Hello Dave, how are you Dave?' | remove_first: 'Dave' }}
Ausgabe
Hello , how are you Dave?
replace_first
Filter
Erstes Vorkommen einer Teilzeichenkette ersetzen
Syntax
{{ 'Hello Dave, how are you Dave?' | replace_first: 'Dave', 'John' }}
Ausgabe
Hello John, how are you Dave?
strip_newlines
Filter
Alle Zeilenumbrüche aus einer Zeichenkette entfernen
Syntax
{% capture text %}
Line 1
Line 2
{% endcapture %}
{{ text | strip_newlines }}
Ausgabe
Line 1Line 2
text_to_html
Filter
Klartext als HTML mit Absätzen und Links formatieren
Syntax
{{ note.notetext | text_to_html }}
Tipp: Wandelt URLs in Links um und setzt Absätze in <p>-Tags
truncate_words
Filter
Zeichenkette auf eine Anzahl Wörter kürzen
Syntax
{{ 'This is a long run of text' | truncate_words: 3 }}
Ausgabe
This is a...
batch
Filter
Array in mehrere Arrays fester Größe aufteilen
Syntax
{% assign batches = entityview.records | batch: 2 %}
{% for batch in batches %}
  {% for item in batch %}
    {{ item.fullname }}
  {% endfor %}
{% endfor %}
Tipp: Ideal für mehrspaltige Layouts oder Seitenumbruch
concat
Filter
Zwei Arrays zu einem neuen Array verbinden
Syntax
{{ group1 | concat: group2 | join: ', ' }}
Ausgabe
John, Pete, Hannah, Joan, Bill
except
Filter
Elemente wählen, deren Attribut NICHT dem Wert entspricht (Gegenteil von where)
Syntax
{% assign not_redmond = entityview.records | except: 'address1_city', 'Redmond' %}
group_by
Filter
Array-Elemente nach Attributwert gruppieren
Syntax
{% assign groups = entityview.records | group_by: 'address1_city' %}
{% for group in groups %}
  {{ group.key }}: {{ group.items.size }} items
{% endfor %}
Tipp: Liefert ein Array von Objekten mit den Eigenschaften .key und .items
select
Filter
Ein einzelnes Attribut aus jedem Array-Element ziehen
Syntax
{% assign names = entityview.records | select: 'fullname' %}
{{ names | join: ', ' }}
first
Filter
Erstes Element eines Arrays
Syntax
{{ entityview.records | first }}
{{ entityview.records.first.fullname }}
last
Filter
Letztes Element eines Arrays
Syntax
{{ entityview.records | last }}
{{ entityview.records.last.fullname }}
size
Filter
Anzahl der Elemente eines Arrays oder Zeichen einer Zeichenkette
Syntax
{{ entityview.records | size }}
{{ 'Hello' | size }}
Ausgabe
42 5
shuffle
Filter
Array in zufälliger Reihenfolge zurückgeben
Syntax
{{ entityview.records | shuffle | join: ', ' }}
Tipp: Gut, um Kundenstimmen oder hervorgehobene Elemente zufällig zu mischen
skip
Filter
N Elemente überspringen und den Rest zurückgeben
Syntax
{% assign words = 'This is a test' | split: ' ' %}
{{ words | skip: 2 | join: ', ' }}
Ausgabe
a, test
take
Filter
Die ersten N Elemente eines Arrays nehmen
Syntax
{% assign words = 'This is a test' | split: ' ' %}
{{ words | take: 2 | join: ', ' }}
Ausgabe
This, is
plus
Filter
Zwei Zahlen addieren
Syntax
{{ entityview.page | plus: 1 }}
Ausgabe (page = 5)
6
minus
Filter
Eine Zahl von einer anderen abziehen
Syntax
{{ entityview.page | minus: 1 }}
Ausgabe (page = 5)
4
times
Filter
Zwei Zahlen multiplizieren
Syntax
{{ 10 | times: 2 }}
Ausgabe
20
divided_by
Filter
Eine Zahl durch eine andere teilen
Syntax
{{ 10 | divided_by: 2 }}
{{ 10.0 | divided_by: 3 }}
Ausgabe
5 3.333333
Achtung: Ganzzahl-Division rundet ab. Für ein Ergebnis mit Nachkommastellen eine Dezimalzahl verwenden.
modulo
Filter
Rest einer Division zurückgeben
Syntax
{{ 12 | modulo: 5 }}
Ausgabe
2
Tipp: Für Zebrastreifen forloop.index | modulo: 2 zuweisen und das Ergebnis vergleichen. Liquid in Power Pages kennt keinen %-Operator
round
Filter
Auf ganze Zahl oder N Nachkommastellen runden
Syntax
{{ 4.6 | round }}
{{ 4.5612 | round: 2 }}
Ausgabe
5 4.56
ceil
Filter
Auf die nächste ganze Zahl aufrunden
Syntax
{{ 4.3 | ceil }}
Ausgabe
5

Filter
Auf die nächste ganze Zahl abrunden
Syntax
{{ 4.6 | floor }}
