Power Pages Template X-Raywas jedes Template mitbringt.

16 Site-Templates, geprüft gegen Microsoft Learn. Für jedes: welches Datenmodell eine neue Site bekommt, was die Umgebung braucht, wie viele Sites Sie anlegen können, ob es einen Migrationspfad gibt und welche Tabellen und Seiten Microsoft dokumentiert.

Was sich 2026 geändert hat

Dynamics 365 heißt nicht mehr Standard-Datenmodell

Seit Mai 2026 legen die Templates Customer Self-Service, Employee Self-Service, Partner und Community Sites im Enhanced Data Model mit Bootstrap 5 an. Voraussetzung ist das Power Pages Core Package ab v1.1.2602.230. Vier Dynamics-365-Templates erzeugen weiterhin Sites im Standard-Datenmodell, auch wenn das Enhanced Data Model aktiviert ist.

Enhanced Data Model

10 Templates

Starter Layouts 1 bis 5, Blank Page, Application Processing, Program Registration, Schedule and Manage Meetings, FAQ sowie vier Dynamics-365-Templates.

Nur Standard-Datenmodell

4 Templates

Customer Portal, Field Service, Modern Community und Order Returns, alle aus Dynamics 365.

Nicht dokumentiert

2 Templates

Event Portal und die Customer Site für Supply Chain Management. Learn ordnet sie keinem Datenmodell zu.

Alle Templates auf einen Blick

Zwei verschiedene Fragen: welches Datenmodell eine neue Site aus dem Template bekommt und ob sich eine bestehende Site im Standard-Datenmodell migrieren lässt. Dazu das Site-Limit pro Umgebung.

TemplateFamilieNeue Site aus TemplateBestehende SDM-Site migrierenSites pro Umgebung

Migration: Das Migrationstool unterstützt nur Sites, deren ursprüngliches Template als unterstützt gelistet ist. Microsoft rät: Ist Ihr Template nicht gelistet, das Tool auf dieser Site nicht ausführen. Für die vier Dynamics-365-Templates sagt die Seite zum Enhanced Data Model weiterhin, bestehende Sites ließen sich noch nicht migrieren, die Migrationsübersicht führt sie dagegen als unterstützt.

Methode

So wurde geprüft

  • Jede Angabe stammt aus einer Microsoft-Learn-Seite, verlinkt am Template: die Template-Seiten, Enhanced data model, Migration overview und Create additional sites.
  • Tabellen und Seiten stehen nur dort, wo Microsoft sie dokumentiert. Für Dynamics-365-Templates beschreibt Learn den Zweck, nicht den Inhalt.
  • „Nicht dokumentiert“ heißt: Learn sagt weder ja noch nein. Prüfen Sie es in Ihrer Umgebung, bevor Sie sich darauf verlassen.
